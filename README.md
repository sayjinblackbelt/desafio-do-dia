# 🎯 Desafio do Dia

> **Aplicação publicada:** [🚀 Abrir Desafio do Dia](https://sayjinblackbelt.github.io/desafio-do-dia/)

Aplicação web simples e responsiva para gerar desafios rápidos de **Informática, Lógica e Criatividade**, com XP, níveis, sequência, metas semanais, conquistas e histórico local.

## 🚀 Acesso rápido

**[▶️ ABRIR A APLICAÇÃO NO GITHUB PAGES](https://sayjinblackbelt.github.io/desafio-do-dia/)**

O projeto está publicado como uma aplicação estática no GitHub Pages.

## V1

- 90 desafios;
- sorteio aleatório de desafios;
- desafio diário determinístico;
- filtros por categoria e nível;
- pontuação em XP;
- níveis e títulos de progressão;
- sequência de dias;
- histórico de desafios concluídos;
- metas semanais;
- sistema de conquistas (badges);
- progresso salvo no navegador com `localStorage`;
- interface responsiva;
- HTML, CSS e JavaScript puro.

## Como usar

1. [Abra a aplicação](https://sayjinblackbelt.github.io/desafio-do-dia/).
2. Resolva o desafio apresentado.
3. Clique em **Concluir desafio** para registrar XP e progresso.
4. Use **Novo desafio** para explorar a base de desafios.
5. Consulte histórico, metas e conquistas ao longo do uso.

O progresso é individual e fica armazenado no navegador usado para acessar a aplicação.
