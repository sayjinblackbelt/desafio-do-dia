# 🎯 Desafio do Dia

Pequeno projeto web para gerar desafios rápidos de **Informática, Lógica e Criatividade**.

## Funcionalidades

- Sorteio aleatório de desafios
- Filtro por categoria
- Filtro por nível
- Interface responsiva
- HTML, CSS e JavaScript puro

## Estrutura

```text
├── index.html
├── style.css
├── script.js
└── README.md
```
