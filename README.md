# 🎯 Desafio do Dia

Aplicação web simples e responsiva para gerar desafios rápidos de **Informática, Lógica e Criatividade**.

## V1.1

- sorteio aleatório de desafios;
- filtros por categoria e nível;
- pontuação em XP;
- registro de desafios concluídos;
- níveis e títulos de progressão;
- sequência de dias;
- progresso salvo no navegador com `localStorage`;
- interface responsiva;
- HTML, CSS e JavaScript puro.

## Como usar

Abra o projeto no navegador ou publique-o com **GitHub Pages**.

O progresso é individual e fica armazenado no navegador usado para acessar a aplicação.
